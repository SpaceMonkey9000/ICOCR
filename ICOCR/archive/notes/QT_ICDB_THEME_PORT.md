# ICOCR 0.9.0-qt2 — ICDB visual style

Baseline: `ICOCR_0.9.0_qt2_PreTracking_Pinout_Zoom.zip`.

- Replaced the six ICOCR stylesheet themes with ICDB Revision 9/11 original Qt Fusion palettes: Light and Dark graphite.
- Native Qt Fusion controls (rounded/native buttons and tabs) replace the square ICOCR stylesheet.
- Preserves SVG inversion in dark mode, video viewer background and pinout zoom/pan.
- Previous theme preferences map dark/graphite/slate -> Dark graphite, and light/classic/warm -> Light.
- Windows dark title-bar preference applied where supported, like current ICDB.
- No edits to OCR, matching, capture, scanning, ONNX segmentation or database modules.
- Windows live GUI and camera tests not performed in this environment.
