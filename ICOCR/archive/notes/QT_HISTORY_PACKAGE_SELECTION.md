# History pinout package selection

The History tab now offers an independent ICDB pinout dropdown above the image. All linked package references are listed via the same labels as the Identify tab. Opening a history entry selects the automatic ICDB recommendation unless that history entry has a manual reference ID. Manual choices are stored with the in-memory history entry and survive tab switches and history list refreshes, but not application restart. Selecting one does not modify the active Identify pinout or its remembered reference. Search datasheet remains available.
